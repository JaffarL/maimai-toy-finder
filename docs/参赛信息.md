# 参赛信息

项目名称：**麦麦寻玩**

名称采用亲切的“麦麦”叠词，配合“寻玩”说明找玩具的用途。仓库与技能目录名采用 `maimai-toy-finder`。

公开仓库：[JaffarL/maimai-toy-finder](https://github.com/JaffarL/maimai-toy-finder)。下列内容用于官方报名 Issue。

报名申请已于2026年10月14日提交：[官方报名 Issue #657](https://github.com/M-China/mcd-developer-innovation-challenge/issues/657)。报名校验结果以该 Issue 下的官方回复为准。

```text
【参赛申请】
项目名称：麦麦寻玩
项目地址：https://github.com/JaffarL/maimai-toy-finder
项目简介：看到喜欢的麦当劳玩具，发张图，找门店。麦麦寻玩利用AI客户端现有的看图能力识别玩具系列，再通过麦当劳官方MCP查询指定城市和商圈的门店菜单，返回提供该系列的门店、地址、套餐及查询时间。支持照片、截图、文字名称、预约菜单和实时系列发现，以技能插件形式安装使用。
```

报名入口：[麦当劳开发大赛官方仓库](https://github.com/M-China/mcd-developer-innovation-challenge)。报名截止：2026年10月25日23:59，北京时间。
